THƯ MỤC icon/ — nơi đặt ảnh cho web
=================================

1) AVATAR: đặt ảnh tên  avatar.png  (hoặc avatar.jpg / avatar.webp) vào thư mục này.

2) ICON ỨNG DỤNG: đặt ảnh PNG vào thư mục này, đặt tên đúng như bảng dưới đây.
   Mục nào có file đúng tên thì tự hiện icon; không có thì hiện chữ cái đầu như cũ.
   (Mục đã điền icon trong config.js — ví dụ favicon(...) — vẫn dùng như cũ.)
   Tên file = tên ứng dụng viết thường, không dấu, khoảng trắng/ký tự lạ thành dấu gạch ngang. GitHub Pages phân biệt hoa/thường nên hãy viết thường hết.
